# Family Tree in C

## About the program:
This program is to print a simple family tree using the C programming language. It takes input of seven family members, stores it, connects it, and prints it in a tree structure.

## Features:
- Stores name and age of all the 7 family members.
- Uses a Person structure to represent each member of the family.
- uses dynamic malloc memory allocation.
- Links children to their parents using pointers.
- Displays family relationships and a visual family tree.
- Free the allocated memory using free()

## How to compile and Run:
  - first save the file with ctrl + s.
  - compile it using command gcc family_tree.c (file name).
  - Then run it using command ./a.out
  - we can also check if there are any memory leaks using command valgrind --leak-check=full ./a.out.
